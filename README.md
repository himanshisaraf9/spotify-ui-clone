# Spotify UI Clone

A Spotify-inspired web player interface built using **HTML and CSS**.

I created this project to practice frontend development and understand how to recreate a real-world website layout using CSS.

## Tech Stack
- HTML5
- CSS
- Font Awesome
- Google Fonts

## Features
- Sidebar with navigation and library sections
- Sticky navigation bar
- Music cards and playlist layout
- Bottom music player interface
- Hover effects and transitions
- Basic responsive styling

## What I Learned
- CSS Flexbox and positioning
- Styling and layout design
- Hover effects and transitions
- Working with images, icons and fonts
- Media queries

## How to Run

1. Clone the repository:
    
   ```bash
   git clone https://github.com/YOUR-USERNAME/spotify-ui-clone.git
   ```
   
2. Navigate to the project folder:

   ```bash
   cd spotify-ui-clone
   ```

3. Open `index.html` in your browser.
